# Rootify roadmap (worldwide rebuild)

## Phase 1 — foundation

- [x] Lovable Cloud on, Google Maps connected
- [x] Database: profiles, trips (drafts + plans), preferences
- [x] Sign-in (email + Google), keep users signed in, greeting from device clock
- [ ] Logo cropped to circle, tagline in full, copper/navy theme, light/dark
- [x] Bottom tabs: Home, Search, Map, My Trips, Profile + Settings
- [ ] Trip setup: origin/destination autocomplete, dates, day hours, budget, group, interests + Other, transport modes, toggles, Create Plan + Save Draft
- [ ] Real places (Google Places, OpenStreetMap fallback), Open in Maps, verified badge
- [ ] Weather: origin vs destination, per-day labels/advice, Typical beyond forecast
- [ ] Hour-by-hour timetable, 2-3 options per slot, no repeats, hotel + 2 alternatives, nearby
- [ ] Transport legs per selected mode, real transit lines only when Google returns them
- [ ] Map tab with numbered pins and routes

## Phase 2 — live repair

- [ ] Arrived/Leaving, Demo Clock, triggers, ranked Plan B, hard constraints, Accept/Reject/Undo, Travel Repair Score

## Phase 3 — languages and agent

- [ ] English/Tamil/Hindi, local-script names
- [ ] Rootify Agent chat with guided mode
- [ ] Save/restore trips and itinerary option choices for signed-in users
- [ ] Loading, empty and error states for search, weather and routes
- [ ] Keyboard navigation, screen-reader labels, contrast on Phase 1 screens
- [x] Safe delete for trips with confirmation and undo
- [ ] Offline cache of saved trips and itineraries
- [ ] Reorder stops and recalculate routes/times
- [ ] Share trips with read-only / edit access (needs companion accounts)
- [ ] Calendar export (.ics) of stops
- [ ] Configurable reminders for upcoming stops and departures
